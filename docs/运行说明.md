# mini-hot 运行说明

> 更新：2026-09-21（Day 7）。当前为**假数据版 MVP**：前端全功能可用，数据是 `data/` 下的占位 JSON，真实数据抓取从 Day 8 开始。

## 一、如何本地运行（30 秒版）

本项目是纯静态网页（HTML + CSS + 原生 JS，零依赖、零构建），但**不能双击 index.html 打开**——浏览器禁止 `file://` 协议下的网页用 fetch 读本地 JSON 文件（安全策略），会导致所有榜单显示「取不到数据」。

正确姿势：在 `mini-hot` 目录起一个本地静态服务，用 `http://` 地址访问。三选一：

**方式 1：Python（本机已装）**

```bash
cd mini-hot
python -m http.server 8137
```

**方式 2：Node（本机已装）**

```bash
cd mini-hot
npx serve .
```

**方式 3：VS Code** —— 装 Live Server 插件，右键 `index.html` → Open with Live Server。

然后用浏览器打开提示的地址（方式 1 即 `http://127.0.0.1:8137` 或 `http://localhost:8137`）。

## 二、如何验证跑起来了

> ⚠️ **改过代码之后**，刷新要用 **Ctrl+F5（强制刷新）**——普通 F5 可能命中浏览器缓存的旧 JS 文件，看到的还是改前的行为（2026-09-22 实测踩过的坑）。第一次打开无需强刷。

1. 页面出现「mini-hot」顶栏 + 4 个来源 Tab（微博/百度/GitHub/B站）；
2. 列表有「【假数据】」开头的标题——说明 JSON 读取成功；
3. 点 Tab 能瞬时换源；点「收藏」刷新后仍在；点「☾/☀」能切深浅色且刷新保持。

## 三、文件结构（谁负责什么）

```
mini-hot/
├── index.html        页面骨架：顶栏 / Tab / 时效行 / 列表区 / 页脚声明
├── css/base.css      深浅两套变量 + 全部样式（含移动端适配）
├── js/api.js         取数：fetch 封装、8 秒超时、结构校验
├── js/render.js      渲染：榜单 / 收藏视图 / 空态 / 失败态 / 骨架屏
├── js/favorites.js   收藏：localStorage 存取（上限 500 条）
├── js/theme.js       深浅模式：手动切换 + 本机记忆 + 跟随系统
├── js/main.js        编排：并行拉 4 源、先到先渲染、Tab/视图切换
└── data/             假数据（结构 = 未来真数据的结构，前端零改动切换）
    ├── weibo.json / baidu.json / github.json / bilibili.json
    └── status.json   各源抓取状态
```

## 四、上线后怎么看（第 3 周启用 GitHub Pages 后）

推送即发布：GitHub Actions 定时抓真数据 → 提交 `data/` → Pages 自动更新，届时直接访问 Pages 地址，无需本地起服务。
