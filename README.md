# mini-hot ｜迷你聚合热搜网站

全网热点，一站聚合。把各平台的热搜榜单汇总到一个页面，一眼看清大家正在关注什么。

> **状态**：开发中。当前仓库处于项目初始化阶段，网站功能尚未开始实现（计划 Day 7 完成 MVP）。

## 项目简介

| 项 | 说明 |
|---|---|
| 项目名 | mini-hot（迷你聚合热搜网站） |
| 做来干什么 | 把多个平台的热搜榜单聚合到一个页面，免去逐个打开 |
| 当前阶段 | 项目初始化（仓库搭建、开发规范、占位页） |
| 计划中的 MVP | Day 7 |

## 关于仓库安全

本仓库使用 `.gitignore` 排除了以下内容，**绝不提交**：

- 环境变量与密钥文件（`.env`、`*.key`、`*.pem` 等）
- 依赖目录（`node_modules/`）
- 本地数据库文件（`*.db`、`*.sqlite` 等）
- 构建产物与日志（`dist/`、`*.log`）
