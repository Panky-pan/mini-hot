全网热点，一站聚合。把各平台的热搜榜单汇总到一个页面，一眼看清大家正在关注什么。

## 如何查看

页面为纯静态、零构建，两种打开方式：

1. 直接双击 `index.html`（Tab 版）或 `index2.html`（双栏版）——本地文件方式下取数可能受浏览器限制，推荐下面这种方式；
2. 起本地静态服务后访问（推荐）：在该目录执行 `python -m http.server 8137`，然后浏览器打开 `http://127.0.0.1:8137/index.html`。

收藏保存在浏览器 localStorage（仅本机）；深浅模式自动记忆。
